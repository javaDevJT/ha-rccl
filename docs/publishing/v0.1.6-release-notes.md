# Royal Caribbean `v0.1.6`

## Changes

- Updates Club Royale offer polling for the June 2026 Royal Caribbean frontend
  API change.
- Replaces the retired `POST /api/casino/v2/offers/merged` flow with
  `GET /api/casino/v2/offers/list` for offer cards.
- Fetches per-offer sailing details from `GET /api/casino/v2/offers/details`.
- Removes the obsolete `approvedAgencyIds` request field from Club Royale
  polling.

## Notes

- The Club Royale page/session priming behavior is unchanged.
- Offer normalization and the calendar card data contract are unchanged after
  the new list/detail responses are fetched.
